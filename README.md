# سُبحة — نسخة المتصفح

مسبحة للذكر تعمل في متصفحات أندرويد وآيفون، ويمكن تثبيتها على الشاشة الرئيسية وتعمل دون إنترنت.

**الرابط:** https://aszs111.github.io/subha-web/

- خرز واقعي (زيتون، كهرمان، فيروز، يُسر، عقيق، لازورد، لؤلؤ، يَشْم)، وفواصل عند ٣٣ و٦٦ ومئذنة عند المئة.
- السحب يُسقط خرزة واحدة لكل سحبة، وزر نقر كبير (ضغطة مطولة = تصفير).
- العدّ بالصوت ببصمة صوت المستخدم: لا يستجيب إلا للفظ الذكر المسجّل. يعمل داخل المتصفح، ولا يُرسل الصوت.
- تأرجح الخيط مع ميل الجوال، والأذكار والخطة والإعدادات والتلميحات.

الخط: Markazi Text (رخصة OFL، في `assets/fonts`).
